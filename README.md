# Métronome

Un métronome visuel en pixel art, avec la mesure, les accents, les subdivisions et le tempo tapé.

*English version: [README.en.md](README.en.md)*

## Commandes

- **Espace** : démarrer ou arrêter.
- **Flèches gauche et droite** : tempo ±1 · **haut et bas** : ±5.
- **T** : taper le tempo (il suit tes quatre derniers appuis).
- **A** : accent sur le premier temps.
- Clique sur un **temps de la mesure** pour changer son accent : fort, normal ou muet.

## Ce qu’il sait faire

- De **30 à 260** battements par minute, avec le nom du tempo (Largo, Andante, Allegro…).
- Mesures **2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 9/8, 12/8**. En 6/8, 9/8 et 12/8, les temps forts tombent tous les trois.
- Subdivisions : **croches, triolets, doubles croches**.
- Quatre sons : clic, bois, bip, cloche, et le volume.
- Les clics sont programmés dans l’horloge audio : le tempo reste juste même quand l’onglet n’est pas devant.

## Données et synchronisation

Tes réglages sont enregistrés par NeoDex, sauvegardés et synchronisés entre tes PC si la synchro est activée.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Métronome → Installer**.
